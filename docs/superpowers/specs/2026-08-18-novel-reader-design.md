# Windows 桌面小说阅读听书应用 — 设计文档

日期：2026-08-18
状态：已批准（用户确认架构、UI 布局与数据流）

## 1. 目标

开发一个 Windows 桌面应用，支持：

1. 打开小说的 txt 文件，按章节自动划分，选择章节阅读
2. 点击听书，从当前阅读章节开始播放（使用 edge-tts 文本转语音）

## 2. 技术栈与依赖

| 依赖 | 用途 |
|---|---|
| Python 3 + PySide6 | 桌面 GUI（窗口、章节树、正文区、播放控制栏） |
| edge-tts | 文本→语音（微软 Edge 在线服务，需联网） |
| charset-normalizer | txt 文件编码自动检测 |
| pytest | 单元测试 |

## 3. 架构与模块划分

单向依赖、低耦合；每模块单一职责、可独立测试。

```
t2voice/
├── main.py                    # 入口，启动 QApplication
├── core/
│   ├── encoding.py            # 编码检测 + 读取 txt（charset-normalizer，处理 BOM）
│   ├── chapter_splitter.py    # 正则自动识别章节标题，返回章节列表
│   ├── sentence_splitter.py   # 按句号/问号/感叹号切分句子（供 TTS 用）
│   ├── tts_engine.py          # edge-tts 封装：按句合成 → 预取队列 → 播放控制
│   └── progress_store.py      # 记住每本书的阅读位置（JSON，存用户目录）
├── ui/
│   ├── main_window.py         # 主窗口：组装各区域，处理交互
│   ├── chapter_panel.py       # 左侧章节列表（可折叠）
│   ├── reader_view.py         # 右侧正文区（字体/行距调节）
│   └── player_bar.py          # 底部播放控制栏（声线/语速/播放/暂停/上下章/停止）
└── tests/                     # pytest 单元测试
```

模块依赖关系：

- `main_window` 依赖各 UI 组件
- `chapter_splitter` / `encoding` / `sentence_splitter` / `progress_store` 完全独立（纯逻辑，最易测试）
- `tts_engine` 通过 Qt Signal 通知 UI 播放状态，不直接触碰界面

## 4. UI 布局

```
┌──────────────────────────────────────────────────────────┐
│ 菜单栏: 文件(打开) 设置(字体/行距) 帮助                    │
├──────────┬───────────────────────────────────────────────┤
│          │                                               │
│ 章节列表  │           正文阅读区                           │
│ (可折叠)  │   当前章节内容，支持滚动                        │
│ 第一章    │                                               │
│ 第二章    │                                               │
│ 第三章    │                                               │
│ ...      │                                               │
│          │                                               │
├──────────┴───────────────────────────────────────────────┤
│ 播放控制栏: [声线▾][语速▾] [⏮][▶/⏸][⏭][⏹] 状态提示      │
└──────────────────────────────────────────────────────────┘
```

交互：

- **打开文件**：文件对话框选择 .txt → 自动检测编码 → 切分章节 → 章节树填充 → 恢复上次阅读位置并显示对应章节
- **选章节**：点击章节树 → 正文区加载该章节 → 更新进度记忆
- **听书**：点击播放 → 从当前阅读章节开始朗读 → 状态栏显示"正在朗读：第X章"
- **声线/语速**：下拉框实时切换（声线如 晓晓/云希/云健；语速 -10%~+50%）

## 5. 数据流

```
打开txt → encoding检测编码 → 读取全文
      → chapter_splitter正则切分章节
      → 章节树显示 → 点击章节 → reader_view显示正文
      → 点播放 → 当前章节文本 → sentence_splitter切句
      → tts_engine: 句子队列 → edge-tts合成mp3 → QMediaPlayer播放
      → 播完当前句自动下一句；暂停/继续/切章随时响应
      → progress_store记录位置（当前书+章节+滚动位置）
```

## 6. 听书流程（按句合成 + 队列播放）

1. 播放时把当前章节切分为句子列表
2. 后台工作线程**预取队列**：提前合成接下来的 2-3 句（合成是网络 IO，不能阻塞 UI）
3. QMediaPlayer 顺序播放；当前句播放完 → 队列弹出下一句
4. 播放中切声线/语速 → 停止当前合成任务，用新参数重新开始当前句
5. 切章/停止 → 取消合成任务，清理临时 mp3 文件
6. 播放完一章 → 自动续播下一章（可被停止打断）

## 7. 错误处理

- **网络不可用**（edge-tts 需联网）：弹出提示"听书需要网络连接"，播放状态重置
- **编码检测失败**：回退 UTF-8，若仍乱码提示用户
- **无章节标题可识别**：整本书视为单章，仍可阅读和听书
- **临时文件清理**：程序退出时统一清理所有生成的 mp3

## 8. 测试策略

- 单元测试（pytest）：编码检测、章节切分（各种格式样例）、句子切分、进度存取
- 手动测试（GUI）：打开文件、翻章、播放/暂停/切声线/切语速/上下章/停止、断网场景
